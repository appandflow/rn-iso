# Stim documentation website

The Docusaurus source for [appandflow.github.io/stim](https://appandflow.github.io/stim/).

The website is the primary human documentation. Package README files stay
short and link here to avoid duplicate guidance.

```bash
pnpm install
pnpm start
pnpm build
```

GitHub Pages deploys the site from `main` through `.github/workflows/docs.yml`.

## Benchmark video

Render the published prompt-to-proof story from benchmark JSON and its proof
image:

```bash
pnpm run render:benchmark-video
```

The Remotion renderer recreates the published Luna rc.12 JavaScript Stim run as
a 1920×1080 website MP4, a 1080×1350 social MP4, and a poster. Its audited clock
and terminal events come from the benchmark JSON; the matching agent-device
capture is a recreated interaction stored beside the generated files as
`javascript-stim-interaction.mp4`, `javascript-stim-interaction-start.png`, and
`javascript-stim-interaction-end.png`.

`docs/changelog.md` is generated by `scripts/gen-changelog.mjs` from
`../docs/releases/*.md` on every `prebuild`/`prestart`. It is gitignored and
not committed; do not hand-edit or `git add` it.

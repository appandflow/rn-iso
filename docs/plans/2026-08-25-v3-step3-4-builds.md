# rn-iso v3 Steps 3+4: ios and android — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or executing-plans.

**Goal:** `rn-iso ios` / `rn-iso android`: ensure owned device booted, verify Metro, fingerprint, install from cache or build (prebuild/deps-sync first), install, launch wired to the reserved port, attach a device-log collector. Then delete the v2 broker commands the pair replaces.

**Global constraints:** as steps 1-2 (ESM, ASCII, exec.js, config lock, RN_ISO_HOME, fail closed, no new deps). Output discipline: ~8 stdout lines on success; on failure the EXTRACTED diagnostic + log path, never the transcript. All build output to `.rn-iso/logs/build-<platform>.ndjson` (Contract 1, src "build"; raw transcript lines level debug, diagnostics level error, launch record `marker: true`).

## Contract 4: `state.json.lastBuild`

`{ platform, fingerprint, cacheKey, cacheHit, durationMs, appPath, bundleId, startedAt, status: "ok"|"failed", errorCode? }` — written by ios/android beside `supervisor` (merge, don't replace; stop already preserves it).

## Contract 5: collectors

`state.json.collectors = { ios?: {pid, startedAt}, android?: {pid, startedAt} }`. A collector is a detached `node src/collector/run.js --platform p --root r ...` process converting device output to Contract-1 records in `device.ndjson`. A fresh ios/android run kills the previous collector for that platform first; `stop` kills both and clears the key (extend stop in Task I).

## Contract 6: port wiring WITHOUT port-specific binaries

The fingerprint cache shares binaries across workspaces, so the Metro port must never be baked into a build.

- **Android:** after boot/install, `adb -s <serial> reverse tcp:8081 tcp:<metroPort>` — the app's default 8081 maps to this workspace's reservation. (Keep the existing same-port reverse too for tooling that asks for the real port.)
- **iOS bare RN:** before launch, `xcrun simctl spawn <udid> defaults write <bundleId> RCT_jsLocation "localhost:<metroPort>"` — RCTBundleURLProvider reads RCT_jsLocation from NSUserDefaults at runtime. VERIFY against the RN source in /Volumes/ExternalSSD/Developer/react-native (RCTBundleURLProvider.mm) and record the verified key/format in a comment.
- **iOS Expo dev client:** launch via `simctl openurl <udid> "<scheme>://expo-development-client/?url=<urlencoded http://localhost:port>"` where scheme comes from app config; fall back to plain launch + RCT_jsLocation if no scheme. VERIFY the URL shape against /Volumes/ExternalSSD/Developer/expo (expo-dev-client launcher).
- Env `RCT_METRO_PORT` is deliberately NOT passed to builds.

## Error codes (extend `guide errors`)

RN_ISO_NO_METRO (reserved port unhealthy; --no-metro-check overrides), RN_ISO_NO_FINGERPRINT (@expo/fingerprint unresolvable), RN_ISO_PREBUILD_FAILED, RN_ISO_DEPS_FAILED (pod/gradle sync), RN_ISO_BUILD_FAILED, RN_ISO_INSTALL_FAILED, RN_ISO_LAUNCH_FAILED, RN_ISO_NO_SCHEME (no buildable scheme found).

## Command flow (both platforms; flags: --json, --no-metro-check ONLY)

```
root, settings; ensure owned device booted   (fold ensureOwnedDevice out of commands/up.js into src/engine/device.js — up.js keeps importing it until Task I deletes up)
metro: resolveProjectMetro(reservedPort) must be {metro} else RN_ISO_NO_METRO
fingerprint (@expo/fingerprint project-first) -> key = buildCacheKey(platform, hash, {}) (debug/sim defaults)
resolveBuild hit -> skip to install
miss: [ios] prebuild if isExpo && !ios/ ; pod sync if stale (Podfile.lock vs Pods/Manifest.lock differ or Pods absent)
      [android] prebuild if isExpo && !android/
      build -> storeBuild
install (simctl install / adb install -r), port wiring (Contract 6), launch, collector attach, lastBuild written
```

### Task F: iOS build engine

Files: `src/engine/xcode.js`, `src/engine/errors-xcode.js`, tests. Pure parsing separated from invocation (CLAUDE.md). `discoverXcodeProject(root)` (ios/_.xcworkspace preferred over .xcodeproj), `listSchemes` (xcodebuild -list -json; pick app scheme matching project name, else single scheme, else RN_ISO_NO_SCHEME), `buildIos({root, udid, derivedDataPath, logWriter})` -> `{appPath, durationMs}`: xcodebuild -workspace/-project -scheme -configuration Debug -sdk iphonesimulator -destination id=<udid> -derivedDataPath <ws>/.rn-iso/derived-data build, streaming transcript lines to the writer; appPath from Build/Products/Debug-iphonesimulator/_.app (verify Info.plist bundle id matches). `extractXcodeDiagnostics(transcript)` (pure): `error:` lines, Swift/clang file:line:col diagnostics, ld errors, 'The sandbox is not in sync', signing errors — each `{file?, line?, message}`; dedupe; cap 10. Test against REAL recorded failing transcripts you generate (a scratch xcodeproj with a broken .m is fine) plus synthetic cases.

### Task G: shared build plumbing

Files: `src/engine/device.js` (ensureOwnedDevice moved verbatim from commands/up.js + booted-guarantee helper; up.js switched to import from here — the ONE edit outside new files), `src/engine/deps.js` (podsAreStale(root): pure compare of ios/Podfile.lock vs ios/Pods/Manifest.lock, + runPodInstall via exec), `src/engine/prebuild.js` (npx expo prebuild -p <platform> --no-install, only when isExpo && native dir absent; transcript to build log), `src/engine/app-install.js` (installApp/launchApp for both platforms: simctl install/launch, adb install -r + am start resolving the launchable activity via `cmd package resolve-activity` or monkey fallback; iOS RCT_jsLocation defaults write + expo dev-client openurl per Contract 6; android adb reverse 8081->port), `src/collector/run.js` + `src/collector/ios.js` + `src/collector/android.js` (detached collector: ios = `xcrun simctl spawn <udid> log stream --style ndjson --predicate 'processImagePath CONTAINS[c] "<appName>"'` parsed to Contract-1; android = `adb -s <serial> logcat --pid <pid> -v time` after resolving the app pid, level-mapped; both via createNdjsonWriter; SIGTERM clean exit). Tests: pure parts thoroughly; process parts via injected executor; collector line-parsers against real captured samples.

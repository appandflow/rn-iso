# 1.0.0-rc.12

## Fixes

- [`98480e9`](https://github.com/appandflow/stim/commit/98480e9e9ebf2eeeb4472f6d694479bb8a9ae98f) maps slash-separated worktree names to flat `+` paths instead of percent-encoded `%2F` paths, avoiding nested Xcode build failures while preserving the Git branch hierarchy.

## Docs

- [`4f1e3bd`](https://github.com/appandflow/stim/commit/4f1e3bdd0be6e74939b3b5208419b969cb1cea11) defines the benchmark v4 readiness protocol for separate JavaScript and native passes, exact device evidence, failure arms, and timeline artifacts.

## Migration notes

Existing rc.11 `%2F` worktrees are not migrated. Continue or remove them from their current checkout; newly created slash-named worktrees use `+`.

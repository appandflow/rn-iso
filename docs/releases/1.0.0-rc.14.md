# 1.0.0-rc.14

## New

- [`a19b03a`](https://github.com/appandflow/stim/commit/a19b03a4476c9490c162275541e2df4f0980c039) adds a separate JavaScript launch-crash benchmark that measures diagnosis and recovery without mixing those results into readiness charts.
- [`ea416bf`](https://github.com/appandflow/stim/commit/ea416bf71ff6902453b7ca5ca2adea05faad10af) adds audited Android agent benchmark results alongside the iOS results.
- [`c69d4ae`](https://github.com/appandflow/stim/commit/c69d4ae7837fae354772741f6ed4686687231169) adds simulated prompt responses to the benchmark website.

## Fixes

- [`bdd19a6`](https://github.com/appandflow/stim/commit/bdd19a67c676839a40c908e0b841b0daf0b8b345) includes available Expo and bare React Native code frames and stacks in human `stim logs --errors` output. Launch errors now distinguish a live native process from an exited process so agents can avoid unnecessary native rebuilds; an exited process still needs another native launch.

## Docs

- The benchmark presentation now preserves terminal output, follows timeline playback, uses clearer event labels, aligns interaction video, and improves prompt-card spacing ([`573546d`](https://github.com/appandflow/stim/commit/573546da1db36a9254976502d3b5d0deb4c5a5d2), [`07f670a`](https://github.com/appandflow/stim/commit/07f670acb45ef57cfd66dd80ff8d7245ea6dcd5b), [`52f486d`](https://github.com/appandflow/stim/commit/52f486d66053ca76d0ff6124ffbc245a2f7c4a1c), [`0d56b35`](https://github.com/appandflow/stim/commit/0d56b3536efe1e8edb88bedeca70917447ec8703), [`9b1f822`](https://github.com/appandflow/stim/commit/9b1f82255e62b8ce09a5da0deafbe1b8469c7ada), [`f660636`](https://github.com/appandflow/stim/commit/f66063638deb7e725e6173da0b9d5a0d5525b058)).
- [`a41b6cb`](https://github.com/appandflow/stim/commit/a41b6cbd39b60f81c6f241abcafba394265d590f) updates the documented cache-savings examples to match measured results.
- [`8ae44bd`](https://github.com/appandflow/stim/commit/8ae44bdddcfede528c24b9448e9528df9eb206c4) publishes the strict Sol iOS benchmark report.
